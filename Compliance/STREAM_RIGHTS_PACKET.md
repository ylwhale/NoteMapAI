# Stream Rights Packet

This App Store build does not ship a bundled third-party radio-station catalog or third-party streaming URLs.

Earlier review builds included a curated radio catalog. For this resubmission, the catalog and related remote-logo references were removed from the app bundle so the binary no longer provides bundled access to third-party streaming, catalog, or discovery content.

The current build uses only bundled local demo audio for place pins and user-supplied local media attached by the user inside the app.
